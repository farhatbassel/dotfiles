# Portable global configuration

My goal in this repo is to make my configuration portable

## Setup

```sh
mise run setup
```

Setups up the installs for Oh My Zsh, zsh-autosuggestions,
zsh-syntax-highlighting, and Powerlevel10k directly.

Plugins and the theme are found in `${~/.local/share}/dotfiles/zsh`.

Link `~/.zshrc` to the `.zshrc` in this repository.
